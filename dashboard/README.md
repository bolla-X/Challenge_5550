# Dashboard VisionEPI

O dashboard principal é servido pelo Flask em:

```txt
http://localhost:5000/dashboard
```

Arquivos equivalentes usados pelo Flask:

```txt
app/templates/index.html
app/static/styles.css
app/static/app.js
```

Esta pasta `dashboard/` mantém uma cópia organizada para consulta visual e edição, mas a execução padrão usa as pastas `app/templates` e `app/static`.
